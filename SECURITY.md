# Security policy

Toolbox runs entirely in the browser and uploads nothing. Still, report anything that could leak user data (for example a code path that sends file contents over the network), enable script injection, or tamper with the deployed site.

## Reporting

Use GitHub's **private vulnerability reporting**: Security tab, "Report a vulnerability". Please do not open a public issue for security problems. Include the affected URL or file, steps to reproduce, and impact. Expect a first reply within 7 days.

## Scope

In scope: this repository and https://surajrajput1024.github.io/toolbox/. Out of scope: vulnerabilities in your browser, or in bundled libraries that are already fixed in a newer upstream release (open a normal issue to request an update).
